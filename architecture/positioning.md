# CSec Platform Positioning

## What CSec Is

CSec is a **scripted pentest orchestration and evidence platform** built for enterprises and security consultancies that need to:

- run offensive security assessments against APIs and application code at scale
- define and execute custom pentest scenarios and workflows without rebuilding tools
- maintain a unified timeline of security testing activity and progression
- keep sensitive test data and evidence under their own control
- integrate multiple security tools (OWASP ZAP, Semgrep, custom detectors) into one coordinated workflow

CSec is not a passive scanner or posture management tool. It is an **orchestration layer for active pentesting** that treats every scan as a deliberate, traceable, evidence-backed event.

## Target Buyers

- **Enterprises** with internal security teams doing API and code assessment at scale
- **Security consultancies** needing a unified platform to orchestrate pentests across multiple clients
- **Teams** that value controlled, self-hosted infrastructure and audit trails over SaaS convenience

## Core Differentiators

### 1. Scripted, Pluggable Scenarios
Clients define their own attack logic in a simple scripted format. No vendor lock-in to predefined checks. The platform becomes a vehicle for *their* pentest methodology, not a replacement for it.

### 2. Customizable Toolchain
Built on OWASP ZAP + Semgrep + custom detection rules, with client control to add/remove/swap tools via the platform UI. Enterprises don't have to accept vendor defaults.

### 3. Multi-Tenant, Multi-Project Model
Designed for security teams running dozens of assessments across internal projects and external customer engagements. Timeline-based timeline view across all activity.

### 4. Self-Hosted and Controllable
Data stays on your infrastructure. No telemetry, no vendor access, full audit trail under your control.

### 5. Unified Pentest Lifecycle
From initial scan → scenario execution → custom agent logic → report generation → evidence storage → timeline view. Everything in one workflow with full traceability.

## What CSec Is Not

- A replacement for SIEM or continuous posture monitoring
- A threat intelligence or dark web scanning platform
- A magic "find every vulnerability" tool
- A substitute for experienced penetration testers
- A SaaS platform (self-hosted by design)

## Positioning Statement

CSec is the orchestration engine for offensive security teams that need to run systematic, repeatable pentests at enterprise scale while maintaining full control over their data, tools, and evidence.

## Primary Use Cases

1. **Enterprise Internal Pentesting** — Run scheduled API and code assessments across internal projects with audit trail and timeline view
2. **Consultancy Workflow** — Execute custom client pentests using the consultancy's playbooks and scenarios, unified reporting across engagements
3. **Compliance and Evidence** — Generate tamper-evident, client-approved evidence reports with traceability and timeline for audit and governance

## Success Metrics

- Reduce pentest execution time by 60% through orchestration
- Maintain 100% audit trail and evidence integrity
- Enable non-expert teams to run repeatable, high-quality pentests
- Support multi-tool integration without rewriting logic for each tool
